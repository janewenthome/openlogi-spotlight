# Requirements

- macOS computer with a mouse whose button can be remapped to a keyboard shortcut.
- OpenLogi installed for Logitech HID++ button mapping.
- A companion app that can be launched locally without an account or network service.
- One custom mouse button toggles a cursor-centred spotlight during slide playback.
- The overlay must be click-through and must not prevent the presentation app from receiving mouse input.
- The first target is macOS 13+; packaging should be easy to extend to signed GitHub releases.
